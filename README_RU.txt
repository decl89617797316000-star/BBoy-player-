WINDOWS MINI PLAYER — исходный проект

Что есть в этой первой сборке:
- компактное окно поверх рабочего стола, позиционируется над панелью задач;
- каталог интернет-радио Radio Browser и поиск станций;
- воспроизведение прямых радио-потоков и локальных аудиофайлов;
- импорт аудиофайлов в папку Музыка\Mini Player;
- загрузка по прямой HTTP(S)-ссылке на файл, если скачивание разрешено;
- кнопки открытия YouTube и VK в браузере по умолчанию.

Что пока НЕ реализовано:
- встроенное управление YouTube/VK внутри панели и поиск по их каталогам;
- извлечение защищённой музыки YouTube/VK и конвертация потоков в MP3;
- гарантированная поддержка каждого радиоформата (HLS и некоторые AAC/HTTPS потоки могут не открыться).

СБОРКА БЕЗ УСТАНОВКИ Visual Studio:
1. Создай новый GitHub-репозиторий.
2. Загрузи всё содержимое архива в корень репозитория.
3. Открой Actions → Build Windows Mini Player → Run workflow.
4. После завершения открой артефакт Windows-Mini-Player и скачай ZIP.
5. Распакуй и запусти WindowsMiniPlayer.exe.

Требуется Windows 10/11 x64. Сборка self-contained включает .NET runtime.
При первом запуске Windows может показать предупреждение SmartScreen, так как приложение не подписано.

Папка музыки по умолчанию: %USERPROFILE%\Music\Mini Player
